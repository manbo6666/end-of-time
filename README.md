# 时间的尽头 · The End of Time

基于 Three.js 的交互式黑洞与行星艺术网页。以弯曲光线、吸积盘、星海和四颗轨道行星，呈现宇宙暮年的三个瞬间：余晖、静默、新生。

## 功能

- 黑洞光线弯曲、光子环与吸积盘视觉效果（艺术化近似，并非科学模拟）。
- 四颗具有不同材质和轨道的行星，包含环状气态行星。
- 鼠标环绕、滚轮缩放；手机单指旋转、双指缩放。
- 暂停、倒流与时间流速调节，引力脉冲和三段时间回声。
- 程序生成环境声音、全屏模式，以及移动端自适应画质。
- 构建后的页面资源随站点提供，无需加载外部字体或 Three.js CDN。

## 本地运行

安装 Node.js 22 或更新版本，在项目根目录运行：

```sh
npm install
npm run build
npm start
```

在浏览器打开 http://127.0.0.1:4173 。修改源码后需重新运行 `npm run build`，然后刷新页面。也可使用 pnpm 和仓库中的锁文件安装依赖。

需要支持 WebGL 2 的现代浏览器及硬件加速。声音需要点击声音按钮后启用，实际帧率取决于设备 GPU。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标拖动 / 单指滑动 | 环绕黑洞 |
| 滚轮 / 双指缩放 | 拉近或远离 |
| 空格 / R | 暂停或继续 / 逆转时间 |
| 1、2、3 | 切换章节 |
| G | 引力脉冲 |
| H / M / F | 隐藏界面 / 声音 / 全屏 |
| 点击菱形光点 | 收集时间回声 |

## 静态部署

运行 `npm run build`，将 `dist/` 内全部文件上传到静态托管平台。构建命令为 `npm run build`，输出目录为 `dist`。无需数据库、服务器端 API 或密钥。

请通过 HTTP/HTTPS 访问，不要直接双击 HTML 文件。托管平台的默认域名有效期和各地区网络可用性由平台决定；公开源码并不等于已开通在线网站。

## 源码结构

- `src/main.js`：场景、交互、音频、动画与后期处理。
- `src/black-hole.js`：黑洞着色器与光线弯曲效果。
- `src/planets.js`：行星材质和轨道。
- `src/index.html`、`src/style.css`：界面和响应式布局。
- `build.mjs`：esbuild 静态打包。
- `server.mjs`：仅监听本机的预览服务器。
